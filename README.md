📺 Portafolio Dinámico - Theme: Green Room (Deltarune)

Este proyecto mejoro al ser una evolución del portafolio personal estático, convertido ahora en una aplicación web dinámica utilizando PHP y MySQL. El diseño mantiene la estética de la "Green Room" del Capítulo 3 de Deltarune.

🎯 Objetivos del Proyecto
* Conversión a PHP: Cambiamos del archivo "index.html" a "index.php" para manejar lógica de servidor.
* Sistema de Notas (CRUD): Implementación de un formulario funcional para agregar, leer, editar y eliminar notas en tiempo real.
* Integración con MySQL: Conexión persistente a una base de datos para el almacenamiento de mensajes.
* Filosofía K.I.S.S.: Código limpio, entendible y eficiente.

Este paso del proyecto me ha parecido muy util y entretenido, el aprender a como conectar una Bases de Datos sencilla para mantener un sistema sencillo.
